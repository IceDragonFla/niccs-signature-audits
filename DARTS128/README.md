# DARTS128 (1-2b 模式) · hint 通道密钥恢复攻击（作业）

对 DARTS-128 在 CryptHash 论坛 `(1−b) → (1−2b)` 修订后的参考实现完成的独立
密码分析（教学用途，基于自有/公开材料与本地参考实现，授权上下文同 BiT128 审计）。

**结果（TL;DR）**：(1−2b) 修订迫使验证侧采用 `Āz₁ ± q̂cβ` 双分支（验证方不知
b），而**分支判定可被任何观察者公开重放**——真分支恒匹配，假分支在 ±cα 不跨
量化边界时也匹配（概率 (1−2^d/q)^τ ≈ 0.79）。200 万条公开签名中 21.0% 给出
**100% 确定的 b 标签**（"w+ac 侧还是 w−ac 侧"）。配合 ζ 域标记最小二乘 +
条件化收缩矩修正，**精确恢复 (s₀, s₁, e) 全部 1536 字节（与真值逐字节一致）**，
未修改参考验证器伪造 20/20 接受，三组阴性对照全部拒绝。

| 项 | 结果 |
|---|---|
| 干净标签 | 420,453 / 2,000,000（21.0%），准确率 100.0000% |
| s₀ / s₁（z₁ 通道 LS） | 512/512、512/512 精确（rms 0.12） |
| e（hint 通道 LS + 公钥恒等式） | 511/512 → 恒等式修正 → 精确 |

| 阴性对照 | 硬币符号臂无恢复；e 篡改/签名篡改/pk 篡改全拒绝 |

## 攻击链

```
公开签名 ──► 双分支重放（label_extract.c）
             仅+/仅-匹配 = 干净 b 标签（~21%，零误差）
        │
        ▼
R1  z₁ 通道标记最小二乘 → s₀, s₁
    z₁ = y₁ + (−1)^b(s_c⋆c)，y₁ ~ 超球新鲜噪声
    负循环(斜循环)设计在 ζ_k = e^{iπ(2k+1)/n} 基对角化
    → 每签名 2n-FFT + 逐频点除法（attack.py，自检 vs 稠密 LS @1e-14）
        │
        ▼
R2  hint 通道标记最小二乘 → e（独立交叉路线）
    h·W ≈ y₂ + (−1)^b(e⋆c) − (1−2b)c，W = q/2^d
    居中观测 o = (−1)^b·h·W + c = (e⋆c) + 对称噪声
        │
        ▼
R2b 公钥恒等式（forge.c fixup）：e = q̂β − (A₀s₀ + A₁s₁)
    全解一致性 razor：s 精确 ⟺ e∈{−1,0,1}^512
        │
        ▼
伪造：恢复密钥 + 任取 K → 未修改参考签名器/验证器 20/20 接受
阴性：硬币符号臂退化噪声；篡改 e / 篡改签名 / 错误 pk 全部拒绝
```

## 关键实现陷阱（作业记录）

1. **负循环 ≠ 循环**：R_q = Z_q[x]/(x^n+1) 的乘法矩阵是斜循环的
   （M[i,m] = (−1)^{[m>i]}c[(i−m) mod n]）。直接套循环自相关会令信号完全
   相消（实测：真臂与硬币臂 rms 相同）。ζ 域对角化是精确修复。
2. **h 的 mod-2^d 环绕**：`poly_compress` 的 `& (2^d−1)` 掩码在 q 边界附近
   使 hint 出现 ±1020 编码符号（encoder 的边缘区间即为此设计）；观察者按
   模重居中即还原真实小差值。
3. **双分支歧义**：假分支匹配概率 ≈ (1−2^d/q)^τ——判定必须取"匹配集"
   （仅+/仅−/双/无），不能取"首个匹配分支"。
4. **球拒绝条件化收缩（κ ≈ 0.63）**：‖y‖ 紧贴球半径（d=1536 时标准差
   B/d ≈ 3.9），双球拒绝在 ⟨y, sc⟩ 方向构成近半空间截断，实测
   E[y|acc,b] = −0.63·(−1)^b·sc——标记 LS 估计到的是 α = 0.37 倍缩放信号。
   盲修正：矩估计 E[β̂²] = α²·0.3 + σ²（0.3 = 三元秘密二阶矩，σ 取硬币臂），
   实测 α̂ = 0.367 vs 真值 0.364。修正后加数据即可精确四舍五入。

## 文件

```
code/
  sign_dump.c       插桩签名器（导出 b 真值；逻辑与补丁版 sign.c 一致）
  gen_dump.c        keygen + 批量签名数据生成（公开导出 c/z₁/h + 签名字节）
  label_extract.c   公开侧双分支重放 → 干净 b 标签（0=仅+, 1=仅-, 2=无, 3=双）
  forge.c           fixup（公钥恒等式重构 e）+ 伪造闭环 + 三组阴性对照
  attack.py         ζ 域标记 LS（R1/R2 + 硬币阴性臂 + N 收敛检查点）
  run_all.sh        一键流水线
DARTS_1-2b_攻击报告.pdf/.tex   完整技术报告（机理+结果，14 页）
```

参考实现取自官方提交包（DARTS{128,256,512} 目录），按 CryptHash 论坛
(1−2b) 修订更新后使用；逐文件修改与 sha256 清单见报告参考文献一节。
