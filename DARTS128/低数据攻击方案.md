# DARTS-128 (1-2b) 低数据攻击方案设计

> 目标：将恢复所需的签名量从当前经验工作点 1.4–2.0×10⁶ 进一步下压。
> 本文是设计文档（按审稿意见 4/5/6/8 组织），不是已验证结果；每条方案标注
> 预期收益、依据与风险。现状基线见报告 §6.4–6.6。

## 0. 记账框架：询问量 ≠ 保存量 ≠ 有效样本量

三个量必须分开报告：

| 符号 | 含义 | 当前值 |
|---|---|---|
| N_query | 签名询问量（对签名 oracle 的调用数） | 1.4–2.0×10⁶ |
| N_clean | 干净标签样本（仅哈希分支匹配） | 0.21·N_query |
| N_save | 实际保存的数据量（可压缩，见 §2） | 当前 ~2.6KB/条 |
| N_eff | 进入估计器的有效 Fisher 信息当量 | N_clean |

干净标签率 p_clean = 1−(1−2^d/q)^τ ≈ 0.21 是方案参数决定的常数，无法提高。
因此"N_query 降至 10⁵"意味着"N_eff ≈ 2×10⁴"——对应的 Fisher 每坐标噪声
σ_y/√(N_eff·τ)·(1/ρ) ≈ 0.77，**任何逐坐标估计器都不可能给出三元精确解**
（信息论下限 1.7×10⁵，见报告 §6.4）。所以低数据方案只有两条路：

1. **让恒等式约束承担更多**（联合译码，§3）——把 512 条 mod-q 校验的冗余
   全部用起来，而不是只当事后完成器；
2. **从模糊签名回收信息**（软判决，§4）——严格论证后的结论是"双匹配样本
   一阶无信息"，但**软信息路线并未被排除**（见 §4 的修正后验）。

## 1. 立即可做：流水线与记账改造（无风险）

- **流式累计**：attack.py 已流式读取，但 gen_dump 仍落盘完整签名流。改为
  "签名 → 标签提取 → 累加 Dacc/b0/b1 → 丢弃签名"的在线管线后，保存数据量从
  2.6KB/条 降到 ~50B/条（Dacc+G 累计值与标签），N_save 缩减 50×。注意：
  被丢弃的签名仍计入 N_query（审稿意见 8）。
- **R2/e 通道删除**：e 由公钥恒等式重算（fixup），hint 路线的 e 估计仅是
  交叉校验——低数据模式下可整个删除，节省一半累加带宽。
- **自适应停止**：每批（如 5×10⁴）后检查 (i) min_k D[k] 是否达到阈值
  （弱频点噪声放大可控）；(ii) 联合估计的三元一致性（scan3 坍缩）。坍缩即停。
  预期：幸运密钥在 ~8×10⁵ 停止（实测 key1@950k 闭合、key2@1.25M 未闭合——
  逐密钥方差 ~±15%）。
- **交叉拟合 ρ**：当前 ρ̂ 与 s 估计用同一批数据（≈1% 尺度偏差，不影响舍入
  但审稿上不干净）。改二折：A 折估计 ρ̂、B 折去缩放，交替。改动 ~10 行。

## 2. 三元 MAP 候选排序（替代无信息排序，审稿意见 5）

当前扫描按 |ŝᵢ−round(ŝᵢ)| 排序——对错误位置**零区分力**（已实测证明）。
正确做法是用三元先验 T_p（P(0)=0.7, P(±1)=0.15/each）计算每坐标的后验：

    P(s_i = v | x_i) ∝ φ((x_i/ρ̂ − v)/σ_eps) · P(v),  v ∈ {−1,0,1}

- **排序量**改为 1 − max_v P(s_i = v | x_i)（后验熵或 top-2 边际差）。
- **预期收益**：错误坐标（真实值与舍入决策不符）的后验熵系统性偏高——
  在 σ_eps/ρ̂ = 0.35（50 万条）时，错误坐标的后验错误率 ~46%，正确坐标
  ~8%：排序有区分力但不足以定位全部错误；主要价值是给 §3 的分支定界提供
  每坐标代价函数。
- **风险**：无。改动 ~20 行（two_stage.py/corrector.c 各一处排序键）。

## 3. 联合三元模约束译码（主攻方向，预期收益最大）

### 3.1 问题形式化

求 (s₀, s₁, e) ∈ {−1,0,1}³ⁿ⁵¹² 使得

    A₀s₀ + A₁s₁ + e ≡ q̂β (mod q)，  且  −log L(s₀,s₁) 最小，

其中 −log L 由两条观测通道给出：(i) z₁ 通道每坐标高斯项
‖x_z1 − (s₀,s₁) 分量‖²/2σ_ε²；(ii) 恒等式完成后的残差三元先验项。
**信息论事实**：该系统在任意 N ≥ 0 下解唯一（3^1536 个三元候选 vs q^512
个 RHS，假解期望数 ≈ 0）——瓶颈纯计算。

### 3.2 候选算法与评估

| 算法 | 原理 | 预期 | 风险 |
|---|---|---|---|
| **置信传播（BP）** | 二分图：1024 个三元变量节点 + 512 个 mod-q 校验节点；校验消息用 FFT 计算（稠密行 → 每校验 O(n·q log q)，总 ~1.1e9/迭代，C 可行） | N→3–5×10⁵（信息充足，BP 阈值待仿真） | 稠密图的 BP 收敛性无保证；需仿真标定 |
| **AMP/VAMP** | 把恒等式当去噪观测：VAMP 的 LMMSE 步用 (ĀᵀĀ/σ_η² + I/σ_ε²)⁻¹，三元先验步用软阈值；σ_η²→0 时退化为投影（已实测：放大 1.26×），λ-正则扫描是折衷 | 中 | 已实测裸投影失败；VAMP 的 Onsager 修正是否足够未知 |
| **嵌入格 BKZ-BDD** | [Ā | I | q̂β] 维 1537，目标 (s,e,1) 范数 ≈21.5，uSVP gap ≈22；按 2016 启发式 β≈400+（core-SVP ~2^130）；**带 z₁ 先验的剪枝枚举可显著降 β** | N→10⁵ 时仍需 β≥400（先验剪枝后或可降至 ~300） | core-SVP 2^130 的枚举成本不可行；G6K 筛法超作业范围 |
| **wrap 坐标下降 + 模拟重启** | 已实现（wrap_decode.py）：目标面平坦（真值 k 与局部最优 k 的三元距离相同），单次下降困在局部最优 | 已实测失败 | 多重启的期望改进有限 |

### 3.3 建议路线（按性价比）

1. **BP 仿真先验证阈值**（1–2 天）：在合成数据（已知 s、已知噪声模型）上跑
   512 校验的 mod-q BP，标定 N_query-vs-成功率的曲线。若 BP 在 3×10⁵ 闭合
   （对应 N_eff 6×10⁴），则实装。
2. **实装 BP**（3–5 天）：C 实现，FFT 校验更新 + 三元变量节点；初始化用
   现有 z₁-LS 的对数似然。
3. **与现有完成器串联**：BP 输出的 top-2 候选 → scan3 深度-2 收尾 → fixup。

### 3.4 诚实的收益上限

信息论下限 1.7×10⁵（Fisher 地板 + 深度 3 完成器）。**BP 的实际可达点预计
3–6×10⁵**（BP 阈值通常在 Fisher 地板的 1.5–3 倍处）。相对当前 1.4–2.0×10⁶
的削减为 **3–5 倍**；到 10⁵ 以下（<1.7×10⁵）信息论上不可能。

## 4. 双匹配样本的软信息（审稿意见 7 的回答）

**严格结论**：镜像对合 (y,b,coins) → (−y,1−b,coins) 逐点保持全部接受条件
（球范数、压缩前置检查的 Comp_d(−x) = 2^d−Comp_d(x) 对称性、hint 的 (1−2b)
结构），故 P(E_both|b=0) = P(E_both|b=1)，P(b=0|E_both) = 1/2 **严格成立**
（报告 §6.4 已补证明）。因此：

- 双匹配样本的一阶信息 = 0（硬结论，不可绕过）；
- **但二阶/条件信息未被排除**：给定双匹配事件，残差模 q 的 wrap 计数向量
  k 的分布仍可能 b-依赖（e_obs 侧车的 ±2–3 残差与分支相关的二阶矩）——
  这是唯一尚未穷尽的模糊签名信息源，预期收益小（O(2^d/q) 级效应），
  建议仅在 BP 实装后作为附加通道评估。

## 5. 决策矩阵

| 方案 | 工作量 | 预期 N_query | 建议 |
|---|---|---|---|
| 流式累计 + 自适应停止 + 交叉拟合 ρ | 0.5 天 | 1.2–1.5×10⁶（幸运 8×10⁵） | **立即可做** |
| 三元 MAP 排序 | 0.5 天 | 对闭合点影响小 | 顺手做 |
| BP 联合译码（仿真→实装） | 3–7 天 | **3–6×10⁵** | 主攻方向 |
| BKZ-BDD（先验剪枝） | 1–2 周 | 10⁵–10⁶ | 超作业范围，记后续工作 |

**底线**：10⁵ 量级（<1.7×10⁵）信息论不可达；3–6×10⁵ 是 BP 路线的合理预期；
当前 1.4–2.0×10⁶ 已是"无 BP"架构的实测最优。
