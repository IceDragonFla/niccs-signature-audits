# NICCS 首轮签名候选的公开数据密钥恢复研究

作者：GLM-5.3 Max、JY Liu（2026-10-19）

本仓库收录我们对五个 NICCS 首轮征集格签名候选的独立密码分析：BiT-128、
DARTS-128、Shuttle、CS-128 与 COMPASS-SIG-128。全部研究在相应提交方
授权（或书面许可的自查场景）下进行；攻击输入仅为公钥与公开签名，不含
侧信道、插桩注入或计时信息。每个方案一个目录，内含学术报告（REPORT.md）、
攻击代码与可公开分发的工件；五个目录共享一个方案无关的恢复框架 umodel。

同一框架下的五种结局，构成学习型密钥恢复攻击的一个完整判定谱系：

| 方案 | 结论 | 关键数字 | 目录 |
|---|---|---|---|
| BiT-128 | **完整恢复 + 伪造** | 4×10⁶ 签名 → s₀ 768/768 精确 + 等价钥，伪造 20/20 | [BiT128/](BiT128/) |
| DARTS-128（1–2b） | **完整恢复 + 伪造** | 2×10⁶ 签名 → (s₀,s₁,e) 1536 字节精确，伪造 20/20 | [DARTS128/](DARTS128/) |
| Shuttle | **安全论证否定 + 部分恢复，端局缺口已定界** | 850 份 5σ 区分；γ 512/512 精确（342M 签名）；N(s₀) 25 s 解出 | [Shuttle/](Shuttle/) |
| CS-128 | **量化壁垒（信号极弱）** | 完美标签 7.6×10⁴ 即恢复，实际标签 52.6%；最优分类器需 2×10⁶ | [CS128/](CS128/) |
| COMPASS-SIG-128 | **结构性零信号** | σ 定律全尺度吻合而 corr 恒为零；w₁ 一致性检查条件化消除信号 | [COMPASS128/](COMPASS128/) |

谱系的两端同样有信息量：BiT 与 DARTS 展示这类攻击打穿时的形态；
CS 与 COMPASS 的否定结论不是"没做出来"，而是逐通道测定过的壁垒——
"信号弱"（随数据量增长终将可攻）与"信号为零"（任何数据量不可攻）
的防御含义不同，区分二者正是判定框架的价值所在。Shuttle 展示第三种
形态：学习路线受挫后转入代数路线（泄漏 → 环元素精确恢复 → 理想格
端局），困难被重构为良定义的开放问题。

## 目录结构

```
BiT128/      hint 通道算子攻击；paper/ 含完整技术报告与通用模型报告
DARTS128/    双分支重放标记最小二乘；14 页攻击报告（PDF/tex）
Shuttle/     方向反转发现 → γ 精确恢复 → 子域塔 / GS 链；docs/ 含四份专报
             与 LaTeX 报告源码；supplementary/ 含完整求解器族与带日期战役日志
CS128/       量化壁垒报告；代码索引指向 umodel 的 cs_* 模块
COMPASS128/  结构性零信号报告；代码索引指向 umodel
umodel/      方案无关恢复框架（SchemeSpec 声明式规范 + 引擎 + 解码阶梯
             + 适用性闸门 + 自测）；CS/COMPASS 的实验模块在其中
```

各目录的 REPORT.md 是入口读物：怎么恢复的、能恢复多少、下一步优化
方向、复现指南，四个问题各有一节；报告之间的交叉引用（如 BiT 与 CS
的同族对照、COMPASS 判定对 Shuttle 配对方法的借用）标注在正文里。

## 复现总则

1. **秘密数据不入库**。真实密钥、签名 dump、含真值侧车的插桩数据一律
   不分发；各攻击脚本在数据缺失时自动跳过并注明。BiT-128 的公开统计量
   工件（artifacts/）足以端到端复现密钥（sha256 验收），是"仅凭公开
   工件复现"的完整示范。
2. **参考实现**取自 NICCS 首轮官方提交包（Shuttle 官方工件已与审计副本
   逐字节核对一致）；我们对实现的所有修改（插桩、(1–2b) 修订移植）都有
   逐文件备份与 sha256 清单，见各目录。
3. **自测先行**：`python3 umodel/selftest.py`（29 项）通过后再跑各攻击
   管线。

## 伦理与披露

五项研究均在授权审计框架内完成（各报告首节注明授权形态与日期）。对
Shuttle 的两行修复建议已按授权渠道向发布方通报；对本仓库的全部否定性
结论，我们逐条标注证据强度（已证 / 部分刻画 / 高置信推断），不把推断
写作定论。各报告设更正记录一节——审计过程中被撤回的早期结论（BiT 的
z₁ 饱和伪象、CS 的移位 UB 误报、Shuttle 的早期线性求解假象）原样保留，
它们对后来者的价值不小于正面结果。
