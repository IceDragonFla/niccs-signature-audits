# BiT-128：仅凭公开签名完成等价私钥恢复（hint 通道算子攻击）

[English README](README.md)

对 **BiT-128**（下一代商用密码算法计划签名候选 *sign-02*）的独立密码分析，
在所有者授权下针对提交方自有参考实现完成。

**结果**：仅凭 **400 万条普通签名**与公钥——无侧信道、无插桩、无计时——
我们精确恢复 `s0`（768/768 系数）、构造**等价签名密钥**，
并产生通过**未修改参考 C 验证器**的新鲜消息伪造签名
（20/20 接受，4 组阴性对照全部拒绝）。

**出处与时间线**：本次所有者授权审计于 **2026 年 9 月 20 日启动**。
核心缺陷定位（共享双峰符号位的联合分布泄露）、`z0` 标签通道、等价私钥代数、
以及参考验证器伪造闭环均在审计第一阶段完成并留有带日期的本地记录；
hint 通道及其算子处理随后完成。全部工件带日期戳、可确定性复现。

## 攻击路线（我们的路线）

```
公开签名 ──► z0 通道符号标签（96.2%）
        │
        ▼
HINT 通道：签名侧 hint 论证式
    w_a = w − z2 + b0*c_signed（+ 行 0 的 b 修正）中，
    w 与 z2 里的 y2 相互抵消——w_a 与新鲜掩码无关：
    w_a = base − (R * c_signed) + ⋯，其中 R = b0 − e
    ⇒ 公开的 h 量化的是 (w − w_a) = y2 − (R * c_signed) − ⋯：
       y2 是密度已知的新鲜噪声，R 是等价私钥的全部未知量——
       h 是 R 的直接一阶观测。
        │
        ▼
算子定律：ε 对齐统计量中的确定性结构是 R 的线性泛函。
对齐组合学部分在"挑战位置不重复"的抽样模型下是精确期望，
由 Monte-Carlo 校准（F_op）；接受条件化项未建模、由实证界定
（求逆后残差 σ ≈ 0.10 @ 4×10⁶）。
        │
        ▼
算子求逆 + 逐行标度拟合：解
    (M·I + N·F_op) R̂ = −(γ2/s)·Φ − P₀·M·(1 − 2m/d)·𝟙[i=0]
    标签尺度 s 逐行用整数聚类目标拟合。
        │
        ▼
全解一致性修正器（我们自己的 razor）：解模 q 线性系统
    s0 = A0⁻¹(16·b1 + R)
    仅当候选修正使整个 768 维解全部落入 {−1,0,1}（nbad = 0）才接受。
    阶段化 单点→成对→三元 扫描。
        │
        ▼
等价私钥（ê, b̂0）──► 新鲜消息伪造，未修改参考验证器 20/20 接受
```

N = 4×10⁶ 时直接分类**已经零错误**（无需任何修正）；修正器是纵深防御。

## 哪些是精确的、哪些是等价的

* `s0` 是**精确恢复**：768/768 系数与原钥完全一致，经两条独立恢复路线
  交叉验证，且模 q 解在窗口约束下唯一。
* `(e, b0)` 是**等价补全**：公钥只确定了 R = b0 − e；任何满足
  ê ∈ {−1,0,1}、b̂0 = R + ê ∈ [−8,8) 的组合签名能力相同。我们的补全
  在允许处一律取 ê = 0（26 个强制边界坐标）。验证器无法区分两种密钥的
  签名；两条路线恢复出**同一把**等价私钥（逐字节一致）。

## 通用模型（umodel/）

上述 BiT-128 攻击是通用框架 `umodel` 的第一个已验证实例。框架随本仓库
随本仓库顶层目录 `../umodel/` 发布（架构说明：[../umodel/ARCHITECTURE_v17v18.md](../umodel/ARCHITECTURE_v17v18.md)）：

* **声明式规范**：所有方案特定信息——环代数、掩码模型、通道清单、
  公钥关系、等价密钥规则——集中在唯一的 `SchemeSpec`。引擎、模拟器、
  解码阶梯与验证器只读规范、不读方案代码。
* **机器检查的适用范围**：`check_applicability` 对尚未推导的组合
  （如带符号挑战的矩算子、非 2 幂环次数）**显式拒绝**并给出理由，
  而不是输出未经验证的算子。
* **迁移已验证**：在与 BiT-128 代数结构不同的 循环环玩具实例上
  （循环环 Z_q[x]/(x^d−1)、带符号挑战、q=8380417、不同掩码宽度、K=L=1），
  同一套引擎	extbf{零改动}端到端恢复等价密钥：诊断半分相关 +0.991
  （对照 −0.009）、rounding 一次解码、公开自证 V1–V3 通过、
  s0 与等价密钥对真值精确一致。
* **数据量级无关契约**：任意 N 下管线要么返回自证候选、要么返回
  认证区间 + 所需样本量预测（坐标误差目标语义）；体积扫描证实
  σ ∝ N^(−1/2)（拟合指数 −0.497），经验解码边界与预测一致。
  公共 σ 代理的折叠饱和（σ ≳ 0.3 后不可辨识）以显式下界语义报告，
  不作隐藏。
* **已在真实 NICCS 候选上测试（v4）**：对另外两个格候选的提交者
  参考实现插桩，用同一套引擎跑真实签名数据（需本地审计数据）：
  - **CS-128**（BLISS 式分块双模符号位，20 万条）：潜变量结构存在
    （oracle 验证；若有完美标签 7.6 万条即可恢复），但对称拒绝采样
    使发布边缘分布信息不可见（标签准确率 52.6%；assay 半分相关
    −0.0002 对零假设 +0.0005）——框架的数据驱动适用性闸门据此
    **拒绝**标签路线并给出理由，而不是输出垃圾结果。CS-128 的
    安全性完全押在接受采样的对称性上。
  - **COMPASS-SIG-128**（FS-aborts，无潜变量，10 万条）：
    σ(N) 各尺度吻合定律；掩码受限，所需 N ≈ 4.8×10⁷；半分相关
    −0.04（无信号）。
  判定矩阵（BiT / DLT-toy / CS-128 / COMPASS-128）端到端展示了契约
  语义：四种输入形态、四种诚实输出、同一套代码。
* **诚实边界逐条解决（v5）**：v4 的每条“明确不声称”已闭合或量化：
  （1）带符号挑战的矩算子已推导——E[CᵀC]=τI 精确成立（交叉项消失），
  带符号方案根本无需去模糊；（2）σ 折叠饱和自动回退公开掩码定律；
  （3）required-N 双语义（坐标/解码）都报告；（4）真实打包签名字节的
  纯 Python 解码器（CS-128 rANS + SM3 CTR-DRNG 完整移植；COMPASS
  16 位 z——含“其 shake256 实为 SM3-pseudoXOF 换皮”的发现）对插桩
  dump 整包验证 200/200；（5）CS-128 潜变量信息用精确接受模型 LLR
  量化：+0.180±0.023 nats/签名（8σ，**非零**——对称接受并不完美）
  外加 0.19%/块的 norm 边界确定性揭示——即使最优分类器也需要约
  2×10⁶ 条（实际可达约 3×10⁸），对比完美标签下界 7.6×10⁴。
  参考实现的一处偏离（C+E 合并对齐移位在指数差 ≥64 时为 UB）作为
  未建模层记录。
* **v6（多轮边界闭合，含一次更正）**：（1）**撤回** v5 的“对齐移位
  UB”发现——那是我们插桩 printf 格式串错位（参考二进制中移位计数
  从未超过 2）；真实偏离是定点舍入，已**按位移植**（对捕获的接受
  检验值 240/240 位精确），且**不改变信息界**（实际实现 LLR
  +0.182±0.028 对意图模型 +0.180±0.023）。（2）y₂ 层形式化：y₀/y₁
  被钉死、y₂ 需边缘化；严格 (z₀,z₁) 通道信息 +0.122±0.032
  nats/签名，总量被括在 [0.12, 0.18]。（3）二阶矩路线**精确关闭**：
  实测估计量方差给出 required_N = 4.0×10¹⁰（中位）/4.7×10¹²（p90）；
  套引擎：掩码受限 5.9×10⁸——判定矩阵扩至五形态（BiT / DLT-toy /
  CS-128 / COMPASS-128 / COMPASS-128）。

## 更正日志（透明度）

* 我们早期的笔记曾声称 z1 回归路线"精度饱和于 65–69%、永不收敛"。
  **该说法已撤回**：饱和是我们早期统计量（ψ(z)=sign(z)/(1024−|z|)）加
  符号阈值判决的伪象。对原始响应的普通加权最小二乘按 RMSE ∝ N^(−1/2)
  收敛——已在我们自己的数据上验证（RMSE 0.184 @ 20 万条，
  经公钥修正后闭合）。我们测到的跨数据集确定性结构（零位置相关 0.9907）
  真实存在，但不妨碍正确归一化的回归估计。
* hint 通道、其算子定律、逐行标度拟合与全解修正器是本工作的贡献。
  第二条独立恢复路线强化了结论：两条路线恢复出逐字节相同的等价私钥。
* v3 修订（外部审阅）：修正估计方程的符号排版错误（实现一直使用正确符号）；
  更正标签标度处理（s 作用于全部确定性项）；替换"精确 tent 核"的措辞——
  解析 tent 核是 iid 位置近似（对角超出精确 N·τ 达 (τ−1)/d = 11.3%；
  相对位置互斥 MC 算子的 Frobenius 误差 10.9%）；将接受条件化项声明为
  未建模并由实证界定；撤回 σ(N) 地板公式及其自相矛盾的阈值，改用期望跨界
  错误数判据；更正 cell 区间描述与 q = 39·682 + 283；澄清等价密钥为
  验证等价（非输出同分布）、重叠数据集检查为一致性检查而非独立数据复现。
