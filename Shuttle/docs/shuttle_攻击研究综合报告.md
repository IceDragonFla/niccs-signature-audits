## 0. 执行摘要

**核心发现**：Shuttle 提交物的规范算法 Algorithm 22（及全部 9 个实现变体）把交替级数转移概率 S_v 赋给了**离心**移动（y→y+v），而该方案自己的安全论证（规范书 §4.1，即 ASIACRYPT 2026 论文的引理）要求它赋给**向心**移动（y→y−v）。单个语义位的反转使签名响应分布显著偏离目标高斯：秘密方向投影方差膨胀 +28.5%，公开数据 850 份签名即可 5σ 区分出厂实现与正确实现，秘密向量的全部互相关张量随签名公开泄漏。

**文献定性（本轮新增）**：经与两篇迭代拒绝采样论文逐条对照——

- eprint 2024/2052 = Gärtner《Compact Lattice Signatures via Iterative Rejection Sampling》（CRYPTO 2025），是 Shuttle 规范书引用的交替级数构造的理论源头；
- eprint 2026/1991 = Shuttle 本身（Ming 等，ASIACRYPT 2026 接收）——**论文的数学与伪代码均为正确方向（命中区间 ⇒ 移动 y−v）**，我方独立重推论文的不变量公式逐项验证通过；
- 因此本发现是**从论文到 NGCC 竞赛包的重参数化重写过程中引入的转录型缺陷**：NGCC 的方向指派恰好是"Gärtner 的移动方向 × Shuttle 的锚点约定"的交叉组合——两个正确约定的错误杂交（§7.3），一个高置信度的致错机理。

**三档可行性终答**（不变，依据见 §6）：(1) 大幅缩减安全强度——**已做到**（出厂实现的安全论证前提被实测否定，有效 Rényi 超预算约 76 个比特；统计区分 850 份签名）；(2) 从设计上攻破——**对提交物成立**（Algorithm 22 与其自身 §4.1 证明矛盾，出厂代码没有任何有效的 ZK 论证覆盖），但不推翻两篇论文的理论；(3) 恢复等价密钥——**当前不可达**，缺口已被精确刻画为算法/建模问题而非信息缺失。

## 2. 文献谱系与技术背景

### 2.1 技术线

Fiat–Shamir with aborts（Lyubashevsky）→ BLISS 双峰高斯（其拒绝事件成为侧信道攻击面：Flush-Gauss-Reload [GHLB+16]、Espitau 等 [EFGT17]、Pessl [Pes16]）→ **Gärtner 迭代拒绝采样**（eprint 2024/2052，CRYPTO 2025）：把一次性大拒绝分解为 τ 步小转移，每步在相邻点 y±v 间移动，条件于成功**精确**保持目标分布 → **Shuttle**（eprint 2026/1991，ASIACRYPT 2026）：去掉 abort（免拒绝/固定步数），用 Rényi 散度把每步微小漂移累积界住，MLWE 实例化 → **NGCC 竞赛提交物**（本研究对象）：该设计的竞赛重参数化版本。

### 2.2 Gärtner 框架（2024/2052）的核心量

对目标分布 p（高斯）与位移 v，定义

> f_v(y) = Σ_{k≥0} (−1)^k p(y+kv) / p(y)，　g_v(y) = Σ_{k≥0} (−1)^k p(y−kv) / p(y)

转移 z → z+v 以概率 f_v(z+v)、z → z−v 以概率 g_v(z−v)、abort 以剩余概率。其精确平衡恒等式为

> f_v(z+v)·p(z+v) + g_v(z−v)·p(z−v) = p(z) − Σ_{k∈Z} (−1)^k p(z+kv)

（中带外右端求和项为零，分布精确保持；带内需要 abort 吸收）。注意 **f_v 以"到达点"为锚**：S 型级数 S_v(y)：=Σ(−1)^k p(y+kv)/p(y) 是"从 y−v 到达 y"这一 +v 移动的概率。

### 2.3 Shuttle 论文（2026/1991）的转移构造

论文 Figure 1 约定 **p_v(y) = Pr[T_v(y) = y−v]**（减向移动），并"follow the notation of Gärtner"定义

> S_v(y) = Σ_{i≥0} (−1)^i ρ_g(y+iv)/ρ_g(y)，　p_v(y) = S_v(y) 若 ⟨y,v⟩ ≥ 0；1 − S_v(−y) 若 ⟨y,v⟩ < 0

一步输出分布与不变量（论文式 + **我方独立重推验证通过**，含 0 ≤ ⟨y,v⟩ < ‖v‖²/2 的中带边界情形逐项相消）：

> ρ′_v(y) = ρ_g(y+v)·p_v(y+v) + ρ_g(y−v)·(1−p_v(y−v)) = ρ_g(y) − Σ_{k∈Z} (−1)^k ρ_g(y+kv)　（y 在中带 K_v 内）
> ρ′_v(y) = ρ_g(y)　（带外精确保持）

论文 Figure 2 给出三个等价实现 T1/T2/T3；其免对数版本 T3 正是 NGCC 实现的蓝本：

> T3(y,v)：u←U([0,1))；λ←2r²·log u；b←(λ ∈ J_N(y,v))；**return y + (−1)^b · v**

J_N 是区间并 I_N(y,v)（对 ⟨y,v⟩≥0：∪_i [A_{2i+1}, A_{2i})，A_t = ρ_g(y+tv)/ρ_g(y)）在对数域的像，端点为 Q_t(y,v) = ‖y‖² − ‖y+tv‖² = −2t·⟨y,v⟩ − t²‖v‖²。**命中（b=1）⇒ 移动 y−v**。论文的误差核算：ε_id < 2^−44.10、ε_trunc < 2^−47.15、ε_log < 2^−46.74（δ_log < 2^−55）、M2−1 < 2^−68.86、M1−1 < 2^−86.78，Rényi 安全损失 < 1.41 bit（120-bit 组，3-bit 预算内）。

### 2.4 NGCC 提交物与论文版的差异（转录缺陷的引入窗口）

| 项目 | 论文 2026/1991（120-bit 组） | NGCC 提交物（SHUTTLE-128） |
|---|---|---|
| 签名尺寸 | 1175 字节 | 1183 字节（rANS 重整码） |
| 级数截断 N | 75 / 89 / 55（三组） | **29**（i = 0..14） |
| 输入采样器 | k=64 卷积、93-bit CDT、r∈{70,82,99} | k=256、96-bit 反向 CDT、σ_s=825/256 |

| 结构 | (α₁,s₁,s₂) 拉伸 | KVEC=1+ELL+EM 块（含常数 1 块） |

提交物是论文的**大幅重参数化重写**，Algorithm 22 即重写产物。规范书 §4.1 逐字保留了论文的不变量推导（正确），Algorithm 22 的伪代码却把方向写反（§4）。

## 3. 方法论前提：功能测试免疫性引理

**引理（KAT/正确性测试对该类缺陷免疫）**：Shuttle 验证方程依赖双峰恒等式 q·(±1) ≡ q (mod 2q)。IRS 每步转移 z ← z ± v 的**独立符号选择**被该恒等式完全吸收——无论方向指派对错，签名永远合法、验证永远通过。

推论：KAT 一致性、签名/验证正确性、确定性 DRNG 重放等全部出厂测试对本缺陷**原理上不可见**；缺陷只能通过（a）规范书内部一致性审计，或（b）输出分布的统计检验暴露。本研究两者都做了，并给出因果闭环（§5）。

## 4. 核心发现：转移方向反转

### 4.1 形式化陈述

设 v = e_s·X^j·s（挑战系数符号 × 秘密循环移位块）。NGCC 规范书 Algorithm 22（`irs.c::R_transition` 三后端逐行对应）执行：

- `flg ← −1`（默认）→ 移动 z → z − v；
- 区间命中（概率恰为 S_v，见下）→ `flg ← +1` → 移动 z → z + v。

而 §4.1（= 论文正确数学）要求 **P[z → z−v] = p_v(z) = S_v(z)**（⟨z,v⟩≥0 时）。故出厂实现恰好把 p_v 与 1−p_v 互换：**P[向心] = 1−S_v（应为 S_v）**。

**实现核对**：irs.c 的区间端点 lo_i = −2(2i+1)t − (2i+1)²V、hi_i = −4i·t − 4i²V（t = ⟨y,v⟩，V=‖v‖²，i=0..14）与 u = 2r²·ln U（Q44 定点，基-2 对数换算）逐项等于论文 T3 的 J_N(y,v)——**区间测试本身实现正确且锚点正确（当前点 y），唯一错在命中后的移动方向**。这把缺陷隔离到一个语义位，与两行修复（§5.3）互为印证。

### 4.2 机理：为何一个符号位造成 +28.5% 方差膨胀

S_v(y) ≈ (1 + tanh(⟨y,v⟩/r²))/2 是热浴（heat-bath）核的**向心**概率。方向做反后，链的漂移从"把超出的质量修正回来"变为"顺着初始偏置加倍逃逸"：z̃ 沿秘密方向的分量单调放大，其一阶矩仍无偏（符号归一化的恒等式，§6.2），但二阶矩显著膨胀——这正是 HVZK 断言所禁止的"响应分布依赖 witness"的形态。

### 4.3 实测证据（固定密钥，84,000 次转移，2,000 次独立 (y,c,IRS) 试验）

| 统计量 | 出厂版 | 两行修补版 | 独立高斯对照 |
|---|---|---|---|
| Var(⟨y, v_j⟩)/σ²V（控制组） | 1.0061 | 1.0061 | — |
| **Var(⟨z, v_j⟩)/σ²V** | **1.2847** | **1.0063** | 0.9923 |
| 相对控制组膨胀 z 值 | **+35.4σ** | +0.0σ | — |

（隔离真实密钥的 IRS：Var 比 1.2679 → 修补 1.0063，同结论。）分解一致性 z−y = Σ ±rot(e_s,X^j) 精确成立（1,997/2,000，余 3 例为本人贪心恢复的边界误判）；转移概率标定实测逐 bin 跟踪区间公式——**区间测试正确、方向指派错误**的结论双重锁定。

### 4.4 Rényi 预算超支换算（对 §6.1 区分器的定量刻画）

出厂签名 E‖z₁‖² 相对公开可计算理想基线上移 +0.88%（+46,140），200,000 份签名下 z = +76.6 → 每签名均值偏移 δ ≈ 0.171σ。由 KL ≥ δ²/2（高斯次效），实测 **R₂(出厂‖理想) ≥ 1 + 2^−6.1 / 签名**；而规范书断言的 IRS Rényi 因子为 M3 ≤ 1 + 2^−82。**实测超预算约 76 个比特**——论证前提被否定，不是"裕量变小"而是"前提不成立"。

## 5. 因果定位与修复

### 5.1 因果实验（端到端，同密钥同消息流）

- 出厂 vs 修补配对范数检验：20,000 对签名，z = **+135.5**（+0.84%）；
- 出厂 vs 解析基线：200,000 签名，z = **+76.6**（+0.88%），**折算 850 份签名即 5σ**；
- ship−fix 配对差分 R² = 0.9848（修补版是守方能力，作因果证据而非攻击信道）。

### 5.2 修复（两行，三后端各一份）

```c
flag64 = 1;                                          /* was -1 */
...
flag64 = (flag64 & ~cond) | ((int64_t)-1 & cond);    /* hit -> -1, was +1 */
```

等价于 Algorithm 22 第 3 行 `flg←−1`→`flg←+1`、第 11 行 `flg←1`→`flg←−1`（= 论文 Figure 2 的 `y+(−1)^b·v`）。修补后膨胀 1.2847→1.0063（z=+0.0），与 §4.1 精确保持论证一致。验证方程不受影响（mod-2q 恒等式吸收任意符号），但全部 KAT/测试向量需重录。

### 5.3 修复后建议的回归测试（免疫性引理的直接推论）

在 KAT 之外增加**分布性回归测试**：固定密钥统计 Var(⟨z, v_j⟩)/σ²V 与 E‖z₁‖² 相对解析基线的偏移（本报告全部检验量均可自动化为 CI 检验，5σ 阈值下 10⁴ 量级签名即可覆盖）。任何方向/锚点类转录错误都会立即触发。

### 6.1 公开数据区分器（攻击者侧，实测成立）

仅用签名中公开的 z₁ 与规范书公开参数可算的理想基线 Σn·σ_r²/α²：850 份签名 5σ。**免侧信道、免伪造、纯被动**。

### 6.3 密钥恢复攻击现状（2026-10-10 晚间攻坚后重新定性）

- **已实证**：泄漏张量包含秘密的全部互相关信息；oracle 诊断（给定真值模数+真值相对相位，仅 128 个全局相位未知）下多种求解器仍只达 39–42%——**信息充分、瓶颈在求解**。
- **2026-10-10 晚三项决定性诊断**：
  1. **46% 平台的第一层成因 = 模数信息丢失**：此前全部求解器使用单位归一化特征向量，丢弃每频率总模长 λ(m)。恢复模数后（V=√(λ/c₃)·W），**给定真实相位向量 θ，重建即达 762/768（99.2%）**——数据始终足够，是求解目标残缺。
  2. 每频率特征向量方向误差中位数 **5.2°**（95% <20°，特征间隙巨大）——频率域方向信息基本干净，系统偏差主要打在秩 1 分量的尺度上、对方向无害。
  3. **目标函数正确性验证**：交叉对代价 cost(s_true)=2.33e7，比全部已找到的伪解（≥4.4e7）低 2 倍以上——真解是明确的全局最优，此前七族求解器的平台期纯属搜索失败（非偏差导致的错误最优）。
- **端局机械全部就绪**：(a) 已知任意两块精确时，第三块谱除法直接命中 220/256（86%），加整数抛光应达精确；(b) 候选密钥可经**公钥预言机公开验证**（由 s 推 e′=b−a−A·s 并检查小性；harness_forge.c 已端到端验证该推导路径）。
- **剩余唯一瓶颈：128 维离散相位搜索 + 整性**。相位-实性线性化被证明为恒真式（配对约束 m↔(1−m) mod N 施加后实性约束自动满足），无线性捷径。新试求解器（角同步 GN、含模数 GS、θ-L-BFGS、交叉目标 CD、C 模拟退火 30M 步、分块 Gauss-Seidel 闭式 LS+取整、门控锚点——oracle 门控下相位误差仍 39.5°，进入 99.2% 吸引子需 ≲20°）全部平台于 270–460/768：伪整数盆地同时欺骗积分性目标与全部局部搜索动力学。未试强工具：fpylll/BKZ 整数最小二乘（围绕伪盆地线性化 ILS）、多密钥真实环二阶矩学习（去系统偏差）。
- **2026-10-11 终态（全部待办执行完毕，WSL 8 核）**：(a) **4M 签名**（同密钥 2×2M 流合并）：特征向量误差中位 2.4°（p90 6.2°），噪声如预期减半至 879，**真相位重建 768/768（100% 精确）**；(b) **3 个新密钥各 1M**：oracle 重建 767/762/760——"真相位→99%+"跨密钥稳固；(c) **多密钥 LOO 偏差学习**：共性分量 ≈1/3（预测缩减 32–35%），扣除 T_common 后真盆地加深至与最优伪解差 **3.3×**（cost 5.23e9），oracle 重建 dev_max=0.312 全对；(d) **fpylll 格 ILS**：GN-线性化无下降步、LLL+nearest-plane 仅 40 非零局部修正（268/768），768 维 BKZ 时间内不可行；(e) **204 起点 6 进程锦标赛**：全部伪盆地（最优 314/768，代价 1.48–1.57e10）。累计十四族求解器同止步。**最终判定：信息充分、目标可判、端局就绪、数据充足，唯一卡点 = 128 维离散相位搜索**（带极深伪整数盆地的独立算法问题）。LaTeX 终版：`reports/latex/shuttle_attack_report.pdf`（10 页，编译零错误，视觉验收通过）。
- **数据侧**：1M 签名模数噪声折算时域每系数误差 0.57 > 0.5 取整线，精确恢复另需 ≳4M 份签名；偏差/噪声分解（新增）：交叉对残差中 63–73% 为系统偏差（不随 Q 缩减），对角对 95%+（对角通道基本不可用）。
- **环分解路线**（已识别未打通）：γ = s·s̄ 是 Z[ζ₅₁₂] 中的范数型分解，理论上是绕开相位恢复的干净路径；随机噪声已达标的另一面是 **~7% 系统偏差为唯一障碍**（bug 链二阶矩中 y-flag 耦合项）。基于隔离 IRS 模拟器的系统项修正模型留一验证失败——根源：模拟器中 c⊥y，真实签名 c=H(w(y)) 与 y 相关。挑战调制分层解剖（200k 真签 × 每频率调制量分层）未见相关信号，调制假说未获支持。
- **等价密钥 = {sk, −sk}**（双峰符号对称；移位/反射不构成等价密钥）；恢复等价密钥 ⇔ 精确恢复 s（e′ 可由 pk 精确导出）。

### 6.4 三档问题终答

1. **大幅缩减安全强度**：成立——出厂实现的分布性安全论证前提（M3 ≤ 1+2^−82）被实测否定（实测 ≥ 1+2^−6.1/签名），Theorem-5 型归约的分布因子失效，提交物**没有任何有效的 ZK/HVZK 论证**；统计区分 850 份签名。（格问题硬度 core-SVP 估计不受影响——那是 MLWE 难度而非分布问题。）
2. **设计上攻破**：对提交物成立（自相矛盾：Algorithm 22 vs §4.1）；对范式不成立（论文版数学正确，见 §7）。
3. **恢复等价密钥**：当前不可达；需（含 c-y 耦合的精确二阶矩模型）⊕（高密度相位恢复专用求解器）之一，样本另需 ≳4M。两者均已量化。

## 7. 与迭代拒绝采样文献的关系（本轮核心新增分析）

### 7.1 对 Gärtner 2024/2052 的影响：理论未被推翻

Gärtner 的精确平衡恒等式（§2.2）自洽且被我方复推验证；本发现不构成对该理论的反例。但我们的结果表明：**该文献与 Shuttle 论文共用的级数公式 S_v(y) 是一个"方向语义重载"的记号**——同一公式在两文中对应相反方向的移动事件（见 7.3 表）。这类记号重载是转录错误的客观温床。

### 7.2 对 Shuttle 论文 2026/1991 的影响：数学与伪代码均正确，"脆弱性警告"以意料之外形态成真

我方（a）独立重推论文的 ρ′_v 不变量公式（中带内外两种情形）逐项通过；（b）核对论文 Figure 2 伪代码 T1/T2/T3：**命中 ⇒ b=1 ⇒ 返回 y−v，方向正确**；（c）核对论文误差核算（ε_id/ε_trunc/ε_log/M1/M2）内部自洽。因此本发现**不推翻 ASIACRYPT 论文的任何定理**。

论文引言对 Gärtner 框架的批评原文（第 2 点）："*This exact invariant is fragile under implementation... an actual implementation can only use truncated sums, finite-precision arithmetic, and approximate comparisons. These approximations do not merely perturb a number; they define a different transition kernel.*"——作者预见的脆弱形态是**数值近似**；我们的精度审计（§8 阶段 I）表明数值层全部达标，实际击穿安全论证的是**方向语义转录错误**：一个连"改了一个数"都不是、只是"把概率给了反方向移动"的核变换。脆弱性警告成真，但以论文未列举的第三种形态（截断✓、定点✓、**方向✗**）。

### 7.3 致错机理：两个正确约定的交叉杂交（高置信度结构性解释）

| 工件 | 级数 S_v(y) 的指派对象 | 锚点 | 正确性 |
|---|---|---|---|
| Gärtner 2024/2052 | P[(y−v) → y]（+v 移动，**到达**锚点） | 到达点 | ✓（带 abort 精确保持） |
| Shuttle 论文 2026/1991（Fig.1/Fig.2 T3） | P[y → y−v]（−v 移动，**离开**锚点） | 当前点 | ✓（免拒绝，漂移 ≤ ε_id） |
| **NGCC Algorithm 22 / 全部实现** | **P[y → y+v]**（+v 移动，**离开**锚点） | 当前点 | **✗**（方差 +28.5%、γ 泄漏） |

共同原理：两种正确构造中，级数 S_v(x)（沿 +v 方向展开、要求 ⟨x,v⟩≥0 保证交替递减）都是"**与级数展开方向相反的那条边**"的转移概率——Gärtner 里是从 x−v 到达 x 的边，Shuttle 里是从 x 离开到 x−v 的边。NGCC 的伪代码沿用了 Shuttle 的"当前点锚定"循环结构（区间测试逐项等于论文 T3 的 J_N），却把命中解释成 +v 移动——即按 Gärtner 的"移动方向直觉"配 Shuttle 的"锚点约定"。**一步之差，两个正确约定的所有交叉组合中恰好落在唯一错误的那格。**该解释为结构性推断（非文档证词），但它与"区间测试正确、仅方向位错误"的实现层证据完全吻合。

附带说明：我方仅审计了 2026/1991 的当前版本（2026-09-12，ASIACRYPT 版）；不排除更早 eprint 修订版已含反向伪代码。这不影响对提交物的结论——规范书 §4.1 与 Algorithm 22 的自相矛盾独立成立。

### 7.4 与 BLISS 泄漏攻击家族的关系：同族异信道

Gärtner/Shuttle 论文的免拒绝动机之一正是消除 BLISS 类 abort 泄漏面（Flush-Gauss-Reload、Espitau 等、Pessl——后者的微架构/侧信道信道）。我们的发现显示：替代机制被转录反转后，泄漏从**微架构侧信道**（需物理访问）整体迁移到了**签名文本本身**（公开数据、被动、850 份即区分）——攻击成本不降反升为零。攻击属"分布性泄漏→秘密相关统计"同一家族，但信道由设计新引入的确定性双输出转移产生，为该家族的新成员。

### 7.5 对我们文章的定位结论

1. **主张**：对免拒绝迭代拒绝采样实例化的首个方向语义攻击；发现证明-实现鸿沟的"第三种形态"（数值近似之外的语义转录）；给出功能测试免疫性引理、两行因果修复、850 份签名公开区分器、全 γ 张量泄漏地图与恢复瓶颈的完整定量刻画。
2. **不主张**：不推翻 Gärtner 理论与 Shuttle 论文（两者数学正确）；不主张已实现等价密钥恢复（瓶颈已量化：求解器 ⊕ ≥4M 样本）。
3. **普适启示**：Rényi 界的"每一步都数清楚"式核算（两篇论文的核心方法论）对**语义位**零覆盖——需要配套（a）伪代码-证明一致性审计工具、（b）分布性回归测试（§5.3）作为该技术路线落地的标准环节。

## 8. 阶段 I 摘要：精度审计（干净，本发现的"排除法"前提）

对说明书 Theorem 1 的 C1/C2 与全采样管线逐位复算：R₁₀₂₅ = 1+2^−95.40、η = 2^−54.49、p_acc = 0.8903 均与声明一致；96-bit 反向 CDT、ApproxExp（deg-8 多项式+7 次平方）、ApproxLog（最坏 6.02 ulp_q62，Decimal 精确比较）、卷积+拒绝、ref==avx2 全内核位一致（χ²/df=0.9985）。次要发现（不构成可利用漏洞）：SUF-512 组 C2 裕量仅 0.49 bit；出厂表带 −8~19 ulp₉₆ 系统偏差与"可复现"声明矛盾；R_∞ 括注无法复现；θ×L 联合优化显示 96-bit 表有 16–26 bit 冗余（2^64 预算下 70 bit 即可），float64 移植将恰好压穿 C1。**结论：错误不在高斯采样管线——这把攻击面精确孤立到 IRS 转移核的方向指派。**

另记录（引用说明书 Table 12 并经独立复算 primal 144.2 一致）：Shuttle-128 量子 core-SVP 最小值 123.4 < 128、Shuttle-256 组 252.0 < 256——若竞赛评级采用量子度量，两组参数低于标称等级（与本漏洞无关的独立参数问题）。

## 10. 局限与未决问题

1. **精确系数恢复**：需专用整数环面求解器（置信传播/整数最小二乘类）或含 c-y 耦合的精确二阶矩模型，样本 ≳4M（均已量化，列为后续工作）。
