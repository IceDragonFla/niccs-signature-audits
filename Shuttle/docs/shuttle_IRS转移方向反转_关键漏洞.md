# Shuttle IRS 转移方向反转：签名响应分布失真与秘密相关泄漏（关键发现）

> 日期：2026-10-09　授权前提：已获算法发布方许可的实现层攻击研究
> 影响：SHUTTLE-128/256/512 × ref/avx2/avx512 全部 9 个变体（规范书 Algorithm 22 层面的缺陷）
> 严重级：**关键（HVZK/零知识性质在 ~10³ 量级签名上可测失效，秘密子空间泄漏，存在密钥恢复攻击路径）**
> 复现材料：`tmp/wsl_shuttle/`（diff_kernel.c、harness_irs.c、irs.bin/irs_fix.bin、rand.bin、修补脚本内嵌于本文 §5）

## 1. 一句话结论

规范书 Algorithm 22（及全部实现）把交替级数转移概率 **S_v 赋给了"离心"移动（y→y+v），而规范书自己的 §4.1 精确保持证明要求它是"向心"移动（y→y−v）的概率**。实测后果：签名响应 z̃ 沿秘密方向 e_s·X^j 的投影方差膨胀 **+28.5%**（84,000 次转移，z≈35–37σ），z̃ 不服从 D_{Z,r}，模拟器/HVZK 论断（M3 ≤ 1+2^−82）对实现不成立；交换两个移动方向后偏差**精确归零**（1.0063 vs 对照 1.0061，z=+0.0），因果定位完成。

## 2. 缺陷机理

### 2.1 规范书内部自相矛盾

- **§4.1（分析）**：定义 p_v(y) = S_v(y)（当 ⟨y,v⟩≥0），且由输出密度公式
  ρ′_v(y) = ρ_g(y+v)·p_v(y+v) + ρ_g(y−v)·(1−p_v(y−v))
  可知 **p_v(w) = P[w → w−v]**（"减 v"＝向心）。在该指派下条带外精确望远镜相消（ρ′=ρ_g），条带内误差 ε_int ~ 2^−52（Gärtrtner 引理，β=r/‖v‖≈2.8）。
- **Algorithm 22（规范算法）**：`flg←−1`（第 3 行）→ 默认执行 y→y−v（向心）；区间命中（概率恰为 S_v）置 `flg←1` → 执行 y→y+v（离心）。即 **P[向心] = 1−S_v，与分析所要求的 P[向心] = S_v 恰好互换**。
- 数值旁证：S(t) ≈ (1+tanh(t/r²))/2 正是热浴（heat-bath）核的向心概率——方向做反后，链的漂移从"修正"变为"加倍逃逸"。

### 2.2 实现层确认

`irs.c::R_transition`（ref/avx2/avx512 三后端同一逻辑）：`flag64 = -1` 起始，区间命中 `flag64 = 1`——逐行对应 Algorithm 22。KAT 一致性与正确性测试均无法暴露此缺陷：验证方程依赖 q·(±1) ≡ q (mod 2q) 双峰恒等式，对每次转移的独立符号选择完全免疫；签名永远合法，只是分布错了。

## 3. 实验证据（全部可复现）

固定密钥（DRNG 种子固定，‖e_s‖²=86,650，keygen 门限内）+ 2,000 次独立 (y, c, IRS) 试验，84,000 次转移：

| 统计量 | 出厂版 | 按规范书§4.1修补版 | 独立高斯模拟对照 |
|---|---|---|---|
| Var(⟨y, v_j⟩)/σ²V（控制组） | 1.0061 | 1.0061 | — |
| **Var(⟨z, v_j⟩)/σ²V** | **1.2847** | **1.0063** | 0.9923 |
| 相对控制组的膨胀 z 值 | **+35.4σ** | **+0.0σ** | — |

- v_j = e_s·X^j（j ∈ supp(c)，c 公开）；σ=825，V=‖e_s‖²=86,650。
- 分解一致性：z−y 精确等于 Σ ±rot(e_s, X^j)（1,997/2,000；3 例为本人贪心恢复的边界误判，非实现问题）。
- 转移概率标定：实测 P[flg=+1] 逐 bin 跟踪区间公式（0.507/0.545/0.601/0.642/0.700/0.744/0.797 vs 理想 0.50–0.80）——**区间测试本身实现正确**，错的是方向指派。
- E[flg] = +0.140（应为 0 附近的小偏置被反向放大），corr(flg, t_pre)=+0.11：离心漂移直接可见。

## 4. 安全影响（2026-10-10 端到端实验修订版）

> 本节按 200,000 份真实签名的端到端实验（`tmp/wsl_shuttle/shipc_*`）修订：早期草稿中"全互谱张量泄漏""约 600 份签名"两处为过度声称，已按实测改正；并新增对角通道与两个被对称性关闭的通道的定性结论。

1. **HVZK 失效 + 公开数据区分器（可测、攻击者侧）**：出厂签名 z1（公开、可由签名无损解码）的 E‖z1‖² 相对**公开可计算的理想基线**（Σ n·σ_r²/α²，σ_r=825/块宽 α∈{90,10}）上移 +46,140（+0.88%）；200,000 份签名下 z=**+76.6**，折算 **约 850 份签名即 5σ**。配对因果测量（同密钥同消息流出厂版 vs 两行修补版）：mean‖z1‖² 5,290,897 vs 5,246,676，配对 z=+135.5。
2. **密钥泄漏（时域互相关全通道，实测成立；2026-10-10 终版）**：s 三块两两间**全部 6 对负循环互相关 γ_{kk′}(d)** 均被公开签名泄漏：C_{kk′}(d) = c″·γ_{kk′}(d)，c″≈84.0（六对共用），R²=0.92–0.946（200k 签名）。——注：曾两次误判（先声称"全互谱张量"，后撤回为"仅对角"），最终经定义直接计算与真值校准映射两路独立验证确认：**六对全泄漏，此前"跨块抵消"是本方 FFT 共轭映射笔误**。
   频域形态：泄漏 Gram ≈ c₃·ŝŝ*（秩 1 主导）+ **系统性剩余结构**（不随 Q 缩减，1M 签名下 Gram 残差仍 0.66——来源于 bug 链的二阶矩中 y-flag 耦合等非 ŝŝ* 项，精确建模为后续工作）。
   系数恢复现状：交替投影（特征向量锚定+实度规）+ 坐标下降整数抛光，200k/1M 签名下均收敛到"slack≈0.15 的近整数解"，与真值（容许全局移位×符号）重合 **321–357/768 ≈ 42–46%**（大系数多数正确、小系数欠定）；精确恢复需要 (a) 泄漏张量的精确二阶矩模型或 (b) 更多样本+更强整数约束求解器——列为后续工作。
3. **被对称性精确关闭的通道（负结果，机理明确）**：
   - 均值通道 E[z|c]：R_transition 的符号归一化使应用标志的边际**恒等于无偏**（P[+rot] = ½S + ½(1−S) = ½ 恒等式），实测 E[f] = −0.0025±0.0035（84k 次转移，真实密钥）。
   - 跨分量/跨块通道 E[z_k·z_{k'}]，k≠k'：边际**恰好抵消**，实测 rms 0.23（=纯噪声水平；包含 (k,0) 与 (k,k')，k,k'∈{1,2,3}）。早期草稿基于 20k 配对数据的"线性求解恢复 s（mean err 0.45）"为估计器假象（信号≈0 时错误数≈s 的非零系数个数），已撤回。
   - 一切真实信号都在 ship−fix 配对差分（同 y、同 c）中：R²=0.9848 —— 这是**因果证据**，但修补版不是攻击者能力，不能当作攻击通道。
4. **参数整定连带失效**：B_v 门与 β 按 z̃~D_r 校准；实际方差膨胀使 E‖z‖² 上移（z 侧 +28%/方向，公开范数 +0.88%）。
5. **全部 9 个变体同陷**（规范书 Algorithm 22 层面）。

### 2026-10-10 深挖补记：系统项刻画与 oracle 诊断

- **前向模型验证**：已知密钥的隔离 IRS 模拟器（20k 转移）复现实测泄漏 Gram（基线修正后相关 0.784，c3 一致 64.1 vs 62.9）——泄漏路径确认为 IRS 本身，模拟器可作为前向模型。
- **二阶矩模型推导**：量化噪声-flag 耦合项（E[q·f]≠0）与张量 bank（ss/ee/se/1u/u1/1e/e1/J 共 8 基）均不能解释系统剩余（残差 0.73→0.73 / 0.54→0.52）——系统项是密钥的更复杂泛函，精确解析式待推导。
- **oracle 诊断（关键）**：给定**真值模数+真值相对相位**（仅 128 个全局相位未知），AP/坐标下降/L-BFGS 整数罚函数三种求解器均只达 ~39–42%——瓶颈被定性为**环面上带整性约束的相位恢复本身**（存在大量 slack 0.06–0.2 的伪整数解盆地），而非测量噪声（1M 无改善）或模数偏差（oracle 无改善）。突破需要专门的整数环面求解器（如置信传播/整数最小二乘）或加入系数先验（±0/±1、P(0)=0.68）的更强约束。
- **终轮补充（求解器攻坚与本方构造 bug）**：(i) 发现并修复了本方锚定构造中强加的错误频率配对对称（在本变换约定下实度配对并非 m↔N−1−m）——此前全部求解器在错误流形上搜索；修复后 oracle 全环面 L-BFGS 仍陷于坏盆地（罚 306 vs 真解 0）。(ii) 全环面并行回火（16 温度副本+移位族协同移动，12 万步）将罚函数压至 215，重合仍 ~330/768。(iii) **第七族：系数空间 Wirtinger 流**（规范不变目标 G(x)=Σ_m‖Gram(x)(m)−B(m)‖²，梯度经 FD 校验，+ 取整/稀疏近端投影，30 重启）停在 G≈2e7（真解 0，全尺度 7e7）——θ-空间、全环面、x-空间三种表述等价顽固。(iv) 结构定性：每块非零密度 53%（411/768），每个滞后平均 ~660 对乘积贡献——**超出 turnpike 类组合方法适用域**；测量数恰处临界（N 模数 vs N 未知），相位恢复经典困难区。信息充分性由 oracle 构造直接证明（θ*=φ₁ 精确还原），缺口纯在求解器。(v) 数据侧量化：1M 签名模数噪声折算时域每系数误差 ≈0.57 > 0.5 取整线——即使求解器突破，精确恢复还需 ≳4M 份签名。结论：最后一步 = 强求解器 ⊕ 更多样本，两者均已量化，非信息缺失。
- 结论不变：**泄漏本身已完整实证**（全 γ 张量 + 功率谱 + 850 份签名区分器）；"γ 张量 → 精确系数"的最后一步是算法问题而非信息缺失。

```c

...

```
