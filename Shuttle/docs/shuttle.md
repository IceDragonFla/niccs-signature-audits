## 2026-10-10 第七次补充（等价密钥可行性专项核查）

- **等价密钥 = {sk, −sk}**（双峰恒等式的符号对称；移位/反射不构成等价密钥）。恢复等价密钥 ⇔ 精确恢复 s（e′ 可由 pk 精确导出）。
- **环分解路线（新识别）**：γ = s·s̄ 恰为 s 在 Z[ζ₅₁₂] 中的范数型分解——理论上是绕开全部相位恢复困难的干净路径；前提是 γ 精确到整数（随机噪声 0.003≪0.5 已达标，系统偏差 ~7% 是唯一障碍）。

- **三档问题终答**：(1) 大幅缩减安全强度——已做到（证明级+统计级，量化如前）；(2) 设计上攻破——已做到（Algorithm 22 与 §4.1 自相矛盾，出厂实现无有效 ZK 论证）；(3) 恢复等价密钥——当前不可达，精确刻画为：需要含 c-y 耦合的精确二阶矩模型（数学工作）或高密度相位恢复专用求解器（算法工作）之一，样本量另需 ≳4M。

  w_{j+1}(i) = w_j(i)² · |σ_i(c_j)|，
与 |σ(f)| 的具体值无关（f^{2^j} 在定义中精确消去）。链的可行性要求每层取到 |σ(c_j)|≈w_j^{-2} 的反向轮廓乘子——这等价于在每层求解扭曲最短向量本身（gap≈1.01 的 uSVP）。

**本实例的嵌入谱**：log|σ(s₀)| ∈ [−0.166, 3.459]，min|σ(s₀)|=0.847。经典 GS 的多项式时间论证（f^{2^j} 除法压住乘子漂移）隐含依赖 |σ(f)| 一致 >1（NTRU 签名私钥天然满足；我们不满足）。

**实测确认**（真值验证的运行，即发散是数学性质而非实现 bug）：
- v₁ cmax = 22 695（≈e^10）；‖R₁‖=1.68×10^14，v₂ cmax ≈ 5×10^11（≈e^26.5）：对数尺寸每层翻倍，与 w² 律精确吻合；层 2 的 B-步整数性断言失败（v₂ 已垃圾化）。
- 排除的捷径：(i) 子格 v_j²(a₀)——形状可被扭曲最短吸收、尺度不能，实测平方爆炸；(ii) 随机小系数混合降维 512→256——命中指数 1 概率为零（实测 index ~10^500）；(iii) 缩放 v'=2v——代数上 (2^{2^j}R_j)/(2v)^{2^j}=R_j/v^{2^j}，乘子逐元素不变，修复无效；(iv) 二段扭曲/单位再平衡——深层平衡行自身系数 e^{2^j·1.8}，物化不可行。

**对 L-S 张量代数路线的诚实说明**：Lenstra–Silverberg 定理 1.1 声称无条件确定性多项式时间（不依赖嵌入条件），其数据结构为分次张量代数 Λ 与 Witt–Picard 群。我们未能把该张量表示落地为可计算的系数表示（张量平方运算的具体构造在文献中未给出可直接实现的形态）；系数表示下的经典乘子链已如上判定发散。此为本步的开放残留。
