# Gentry–Szydlo 自实现设计（针对 Shuttle mk1 实例）— 2026-10-19

## 实例参数
- R = Z[x]/(x^256+1) = Z[ζ512]，v = s₀（真值 s_true_1m.bin，系数 [-2,2]，‖v‖≈18）
- γ = v·v̄ （系数 [-39,204]，|σ(γ)| ∈ [0.72, 1010]）
- J = (γ₀₁)+(γ₀₂) = (s₀) 已验证；LLL 基 gs_IB.npy（行范数 ~1047-1112，最短行 x₁ = v·r，
  r 积分，log|σ(r)| ∈ [2.15,7.20] —— 缺陷 k=|N(r)|≈e^1200，非单位：**这正是不能走"归一化链"的原因**）

## 核心算法（原始 GS 论文 §7.2-7.5 + 附录 F，已完整逆向）

### §7.2 隐式正交格（扭曲 Gram = 未知乘子的标准 Gram）
B = J 的基，行 b_i = v·u_i（u_i 未知）。D = M(1/γ)（嵌入对角 1/|σ(γ)|）。
**B·D·Bᵀ = U·Uᵀ = 未知乘子的 Gram**（因 t(u_iv·ū_jv̄/γ) = t(u_iū_j)）。
对扭曲嵌入矩阵 E_ij = σ_j(b_i)/√|σ_j(γ)| （×2^40 取整）做 LLL → 变换 A → 新基 A·B，
行 = v·a_i，‖a_i‖ 有界（LLL: 2^255；BKZ 实际 ~10³）。

### Algorithm 1（附录 F 字面）——链迭代，物化对象全部小
状态：B_j = (v_j) 理想的基（小！），γ_j := v_j∘v̄_j（精确），R_j := "f^{2^j}∘v_{j+1}"（物化的小行）。
初值 v_0 = f（不物化），B_0 = J 的基，γ_0 = γ。
迭代 r0（while r0 < r ≈ log2(p−1)）：
(a) G = B_{r0} 行的两两乘积（生成 (v_{r0}²)，rank 256，小）
(b) Gram = G·M(1/γ_{r0}²)·Gᵀ（扭曲以 γ_{r0}²）
(c) LLL/Gram-约化 → A（行短）
(d) A·G = (v_{r0}²) 的新基
(e) 取第 j 行命名 R_{r0} = f^{2^r0}∘v_{r0+1}（= v_{r0}²·c_j，c_j = A·H 的行）
    零因子规避：选行使其理想行列式不被 p 整除
(g) γ_{r0+1} = R_{r0}∘R̄_{r0} / γ^{2^r0}   ← 精确除法（等价小量递推：
    R_{r0}R̄_{r0} = γ^{2^r0}·γ_{r0+1}，γ^{2^r0} = R_{r-1}R̄_{r-1}/γ_{r0}·... 需数值验证公式）
    B_{r0+1} = (v_{r0+1}) 的基（论文 2g 公式抽取损坏；候选用
    (v_{r0+1}) = (R_{r0})·(f^{2^r0})^{-1} = (R_{r0})·conj(f^{2^r0}-ideal)/γ^{2^r0}-型小量组合；
    **用真值验证哪个公式对**）
### Algorithm 1 step 4 —— y 链（全 mod p）
y_1 = R_0（物化）= f²·v₁ mod p；迭代 y ← y²·(修正因子) mod p，使 y_j = f^{2^j}·v_j mod p。
修正因子的代数恒等式需用真值数值钉死（候选：y²·(v_jv̄_j)^{-1}·(v_{j+1}v̄_{j+1})·(v̄_j/v_{j+1})类组合，
mod p 下 v̄-比值 = conj(y-比值) 可算）。
终点：p ≡ 1 (mod 512)，f^{p−1} ≡ 1 (mod p)（R/pR = F_p^256 逐坐标费马）
→ y_final = v_r mod p，系数 < p/2 ⟹ **v_r 精确恢复**。
### f^{p−1} mod 其它素数 + CRT
链的物化行 mod 任意素数 Q 可重放：f^{p−1}·v_r mod Q ⟹ f^{p−1} mod Q = y_Q·v_r^{-1}。
双素数 p, p′ ≡ 1 (mod 512)，gcd(p−1, p′−1) = 512，Bezout: a(p−1)+b(p′−1) = 512
⟹ f^512 ≡ (f^{p−1})^a·(f^{p′−1})^b（mod 各 CRT 素数）⟹ CRT 到精确整数元 f^512
（系数 ~e^{1229}，~1800 bit，可存）。
### 末局：f 从 f^512
mod p₂（ord_{p₂}(512) = 128 的非分裂素数，Φ512 = f₁f₂ deg 128，R/p₂R = F_{p₂^128}²）：
在 F_{p₂^128} 解 X^512 = f^512：≤512 根 = v·ζ^t；由 f₂-分量共轭对称补全；centerlift（p₂ > 2·max|coeff|）
候选 512 个 → 验证 v·v̄ = γ（精确整数）→ **s₀ 恢复完成**（±x^j 歧义即天然等价密钥类）。

## 关键教训（已排除的死路）
1. 朴素和格 Λ₂=I²+γR+σ(I)² 塌缩（det≈4）——错误构造。
2. 归一化链（ideaux.gp 路线）需要 x₁ = v·真单位（缺陷 1）；LLL 最短行缺陷 e^1200，
   且缺陷在单位乘法下不变、随链 6 倍/层指数爆炸 → 必须走原始 GS 的乘子链（本设计）。
3. PARI ideaux.gp：fft 名字冲突（已重命名 fftX 修复加载），但 n=16 内层 petitlll 数值崩坏
   （为 n=1024 调参的精度启发式），不值得继续修。
4. L-S 张量代数路线：理论完备但抽象表示（Gram+G-作用）的平方机制文献未给可直接落地的构造。
