# CS-128 实验代码索引

CS-128 的全部实验脚本位于仓库顶层 `umodel/`（它们是 umodel 框架的组成
模块，共享 `spec.py`/`channels.py`/`engines.py` 等基础设施）。本目录只做
索引：每个脚本复现报告中的哪个数字、需要什么数据。

运行方式（从仓库根目录）：

```bash
python3 umodel/selftest.py        # 29 项数值自测（含 CS 潜变量信息测定）
python3 umodel/<脚本名>.py        # 各专项脚本，入口处有参数说明
```

## 脚本与报告结论的对应

| 脚本（umodel/） | 复现内容（CS128/REPORT.md） | 数据需求 |
|---|---|---|
| `cs_oracle_decode.py` | §2 oracle 臂完整恢复：50 万条 + oracle 块符号 → 密钥（解码语义门限 ~4.8×10⁵） | 本地审计 dump |
| `cs_exact_llr.py` | §4 意图模型精确 LLR +0.180±0.023 nats（8σ）与范数揭示 0.19%/块 | 模型自包含；对照验证需 dump |
| `cs_actual_llr.py` | §6 实际实现 LLR +0.182±0.028（意图 vs 实现偏差） | 捕获的接受检验值 |
| `cs_fixedpoint.py` | §6 定点算术位精确移植（240/240 位验证），含移位语义处理 | 捕获的接受检验值 |
| `cs_z2_marginal.py` | §4 (z₀,z₁) 严格通道信息 +0.122±0.032、总量括界 [0.12, 0.18] | 模型自包含 |
| `cs_moment_bound.py` | §5 二阶矩路线所需样本量 4.0×10¹⁰（中位）/ 4.7×10¹²（p90） | 模型自包含 |
| `cs_em_coldstart.py` | 冷启动墙厚度：EM 循环需要多少先验坐标才能突破（k 网格扫描） | 模型自包含 |
| `public_decoders.py` | §6 rANS + SM3 CTR-DRNG 打包解码器（整包验证 200/200） | 自生成数据可验证 |

## 数据边界

真实签名 dump 与插桩侧车（含 b 真值）属本地审计数据，不入库；各脚本在
数据缺失时自动跳过对应实验并打印原因。公开可复现的部分：解码器正确性、
接受模型与 LLR 计算、样本量预测管线、全部自测。
